# Original system-flow illustration

The first hero animation is original SVG/CSS in FlowMedia.tsx. The explainer uses the original 480x360 silent WebM generated by tools/create-flow-media.cjs, with a self-contained SVG poster and English/Hindi WEBVTT captions. No stock footage, people, statistics or Remotion is used.

The local clip is illustrative, not operating telemetry. Visible transcript/source wording discloses hardware/service configuration and verification requirements. Playback is muted/looped, lazy near the viewport, paused for hidden tabs/user control and disabled for reduced motion or data-saving preference. Static diagram/transcript remain available on failure.

scripts/check-media.cjs enforces 512 KiB video, 32 KiB poster and 16 KiB per caption file; these are chosen engineering caps, not performance claims. It saves actual sizes/hashes in docs/test-results/phase11-media-budget.json and runs during postbuild before standalone asset staging. The legacy background flag now selects only the original poster; absent third-party background references were removed.
