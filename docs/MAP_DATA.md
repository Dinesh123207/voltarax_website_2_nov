# Boundary installation and review

The archive is a Git LFS pointer. Its public upstream is [Tanmay53/india-state-boundries-geojson](https://github.com/Tanmay53/india-state-boundries-geojson), declared Apache-2.0. This identifies an upstream, not an authoritative/current Indian boundary source or a guarantee of underlying rights. The README does not establish the original surveying authority. Do not publish the outline without current accuracy, rights and India publication review.

On 2 November 2026 IST, the original raw file was recovered to ignored `.local-tools/geojson/india_states.original.geojson` for local review only. Exact archive fingerprint: `c7f0189a551d1bbb9d19384a9dc63036041515aad99d62859677ef9fce67c8dd`, 164447698 bytes. Offline CLI found 36 features, 1071165 coordinate pairs and actual property keys `ST_NM`, `state`, `id`. The first two features use `state`; the rest use `ST_NM`. No synthetic/retraced/simplified outline was created. Even compact feature JSON is 41187944 bytes, so this source is deliberately not served to the browser.

1. Open [the actual source file](https://github.com/Tanmay53/india-state-boundries-geojson/blob/master/india_states.geojson) in GitHub. Choose **Download raw file**, not the pointer text. Save the original at the ignored review path above; do not overwrite the reference archive.
2. From `voltarax-web/backend`, run `node --max-old-space-size=768 scripts/verify-geojson.mjs ../../.local-tools/geojson/india_states.original.geojson ST_NM,state`. It prints the real property names, state keys, feature/coordinate counts, bounds and SHA-256, and fails explicitly on a pointer/invalid geometry. This is an offline tool for operator-reviewed local input, not a public upload parser. It does not certify outline accuracy.
3. Obtain a licensed, authoritative, reviewed web-sized WGS84 FeatureCollection. Keep its original license, provenance, review evidence and exact geometry. Automatic approximation of the supplied outline is not authorized. The viewer has an 8 MiB / 250000 coordinate / 100 feature budget. It accepts Polygon/MultiPolygon, closed rings and finite longitude/latitude pairs only. Custom CRS is refused.
4. Save that approved file as `voltarax-web/backend/data/india-states.geojson` (gitignored). Run the same CLI with its actual property keys. Configure `MAP_STATE_PROPERTIES` as a comma-separated property fallback list; if two configured names exist they must agree.
5. Set `MAP_BOUNDARY_SHA256` to the CLI fingerprint and only after review set `MAP_BOUNDARIES_REVIEWED=true`. Set `MAP_SITE_STATE` to the exact state name for the configured `SOLAR_SITE_ID`, with documented operator evidence. Keep the default disabled if inputs/review are absent. Runtime rejects a missing/mismatched/oversized/invalid file and returns Unavailable without exposing filesystem errors.
6. Keep `licenses/india-state-boundaries-Apache-2.0.txt`, Leaflet BSD notice and the new source's notice in each distribution. Replace attribution in the service if a different approved source is selected. Do not label another dataset as Tanmay53's source.

The authenticated map covers only the existing configured site, not a national fleet. Device count is a calculated registry count, not an installed-panel count. Energy integrates valid primary-device power intervals since IST midnight, preserves recorded zero, caps gaps at 15 minutes and discloses coverage. Other states and incomplete/truncated/failed reads remain Unavailable. A table is available when geometry is missing and as the keyboard-accessible alternative. No remote basemap or location service is contacted.
